# 开始使用

## 1. 选择设备包

当前支持 `lckfb-szpi-esp32s3` 与 `xingzhi-cube-154tft-wifi`。核对完整型号和对应接线，再选择固件。源码构建步骤见首页 README。

## 2. 安装固件

构建结果位于 `build/wishos/<设备包>/firmware/`。首次安装使用该目录中的 `flash_args`、分区表和 `runtime.littlefs.bin`；文件系统镜像包含桌面、字体、设置网页和默认应用。固件工具给出的 Flash 地址与所选设备包对应。

后续更新应用程序分区时保留 LittleFS，已有 Wi-Fi 配置、应用和文件继续使用。更换分区布局时按完整迁移流程处理已有数据。

## 3. 配网和设备设置

开机后进入默认桌面。单击移动选择，双击打开当前项，三击回桌面。进入“设置”查看设备地址或开启配网热点；手机连接设备热点后，打开设置页面配置 Wi-Fi。设备连接局域网后，可用页面显示的地址继续配置。

## 4. 连接自己的 Agent

按 [WishOS Hub 的说明](https://github.com/cccat6/WishOS-Hub) 在自己的电脑或服务器运行 Hub，连接已支持的 Harness，再将设备与 Hub 配对。Harness 持有模型登录态、会话与工具授权；WishOS 接收经过检查的应用包和有序操作。

## 5. 制作和使用应用

按住用户键说话，松开发送。可以要求创建倒计时、制作信息面板，或修改当前应用。应用可在桌面再次打开。文本回复始终可读，具备扬声器的设备可选择语音播放。

确定性的计时、按钮和文件操作在设备本地执行。需要 Agent 或远程数据的动作通过网络完成。

## 保存位置

立创板可使用 SD 卡和可写内部文件系统；方屏小智使用可写内部文件系统。下载位置与配额由设备配置决定。录音默认使用短暂压缩 RAM 缓存，可选的 SD 录音归档有独立保留策略。
