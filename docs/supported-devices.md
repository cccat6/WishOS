# 设备支持

首批公开支持以下两个具体设备包：

| 设备包 | 实物验证范围 |
| --- | --- |
| `lckfb-szpi-esp32s3` | LCD、背光与启动 Logo、完整中文字体、按键、触摸、麦克风与扬声器、相机预览/定格、IMU、SDMMC、卡上应用及 NFS 文件访问 |
| `xingzhi-cube-154tft-wifi` | LCD、背光与启动 Logo、完整中文字体、单键菜单/返回、麦克风与扬声器、Wi-Fi、Flash 文件与 NFS、电池采样 |

两台设备都经过语音到用户 Harness、文本/语音回复以及返回桌面的联调。应用预检、安装、显示完成分别有回执。通过某条流程的验证范围以其实际外设和配置为准。

可用交互包括单击切换、双击确认、三击 Home、长按语音；立创板另有触摸操作。启动 Logo 完整写入后开启背光，用户已确认两台复位启动画面正常。

源码中的 C3/S3 无屏配置用于运行时和 SDK 开发。平台、驱动和设备接线各有独立描述，新增设备时可复用这些组件。电子纸原生驱动仍由独立的设备适配工作维护。

后续验证重点包括更长时间的并发压力、无线睡眠与功耗、各设备实际唤醒词效果，以及更多成品硬件。欢迎在 Issue 中提供确切型号、接线资料和可复现步骤。
